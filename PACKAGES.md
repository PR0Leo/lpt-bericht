%% COMPLETE LIST OF PACKAGES AND THEIR PURPOSES

Font and Encoding:
  - fontenc [T1]: T1 font encoding for improved character support and hyphenation
  - textcomp: Additional text symbols beyond standard LaTeX
  - mathpazo [slantedGreek,sc]: Palatino font family with math support
  - helvet [scaled=.95]: Helvetica font for sans-serif text
  - courier: Courier font for monospace/typewriter text

Language and Graphics:
  - babel [ngerman]: Multi-language support for German text
  - graphicx: Graphics inclusion and image manipulation

Mathematics:
  - mathtools: Enhanced amsmath for professional math typesetting
  - bm: Bold math symbols
  - fixmath: Fixes various math font issues
  - amsfonts: Mathematical fonts (blackboard bold, etc.)
  - siunitx: Scientific units and quantities formatting with German locale

Technical Drawing and Code:
  - circuitikz [siunitx, RPvoltages]: Electric circuit diagrams with SI units
  - tikz/positioning: Node positioning in diagrams
  - listings: Source code formatting and syntax highlighting

Floats and Captions:
  - floatrow [facing=yes]: Multiple floats side-by-side and caption positioning
  - caption [labelfont=bf,sf,...]: Enhanced caption formatting
  - subcaption: Sub-figures and sub-tables support

Formatting and Page Layout:
  - enumitem: Enhanced enumeration and list formatting
  - scrlayer-scrpage: Header and footer configuration with KOMA Script
  - microtype: Optical margin adjustment and improved typography
  - hyperref [colorlinks=false,...]: Hyperlinks and PDF properties

Bibliography and Glossaries:
  - biblatex [style=ieee, backend=biber]: Modern bibliography management
  - glossaries [toc, section=chapter]: Acronyms and symbols lists
